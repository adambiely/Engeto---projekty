# Projekt 2 – Správce úkolů s MySQL

Správce úkolů vytvořený v Pythonu s využitím databáze MySQL.

Program umožňuje přidávat, zobrazovat, aktualizovat a odstraňovat úkoly.

Soubor test_main.py obsahuje 6 automatizovaných testů pomocí pytest.

Pro spuštění programu je potřeba MySQL databáze a nastavená proměnná prostředí MYSQL_PASSWORD.
