Projekt 3 – Automatizované testování webu

Automatizované testování webových stránek ENGETO pomocí Pythonu, Playwrightu a pytest.

Projekt obsahuje 3 automatizované testy:

Kontrola hlavní stránky ENGETO.

Kontrola stránky Python Akademie.

Kontrola stránky Termíny kurzů.

Každý test ověřuje více prvků na stránce.
